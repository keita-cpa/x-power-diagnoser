## 1. 自己重要感の充足（人蕩し術・第一の欲動）

人は「自分の価値を認められたい」という欲動を持つ。ただし承認には階層がある:

| レベル | 例 | 効果 |
|---|---|---|
| ✗ ありきたり褒め | 「すごい」「プロですね」「丁寧」 | 価値ゼロ。むしろ「見ていない」ことが伝わる |
| △ 結果の承認 | 「人気があるのも納得」 | 他の誰かでも言える |
| ◎ 固有の事実の言語化 | 「普通なら〇〇するところを、△△している」 | 「ここまで見て、言葉にしてくれた」という感動 |

**鉄則**: 承認は必ず「観察された具体的事実・行動・言葉選び」を根拠にする。
「誰も見ていないようなささいな気遣い」を見抜いて言語化することが最大の承認。

## 2. 群居衝動の充足（人蕩し術・第二の欲動）

人は「孤独でいたくない・仲間でいたい」という欲動を持つ。

- **代弁**: 相手がまだ言語化できていない感情を先回りして言葉にする。本人より正確に言語化できたとき「私のことだ」と立ち止まる
- **共犯者化**: 読者を「ぼくら」側に巻き込み、対象を上座に置く（逆マウント）。固定フレーズの流用は禁止・毎回ゼロから生成
- **破壊要因**: 説教・正論・「〜すべき」は群居衝動を破壊する（「あなたは間違っている」＝「あなたは仲間ではない」のメッセージになる）

## 3. 愛と陽気さ（人蕩し術・底流）

- すべての文章の前提に「相手の幸福を心から願う愛」を置く。テクニックは愛の上でしか機能しない
- 陽気さ: 暗い話・痛みの話でも、最後の一文はそっと上向きに終える。読後感が沈む文章は失敗
- **媚びとの区別**: 承認＝観察された事実の言語化 / 媚び＝根拠なき称賛・迎合。媚びは見抜かれて信頼を毀損する

## 4. おもろい話し方（エンタメ話術）

| 技術 | 内容 |
|---|---|
| フリオチ | 「普通なら〇〇のはず」というフリ → 予想を裏切るオチ・気づき |
| 巧みな例え | 抽象的な感情・概念を、生活感のあるモノ・場面に例える |
| 感情のリアル言語化 | 「嬉しかった」ではなく、その瞬間の身体感覚を擬音（「スッと」「フワッと」）・情景で描写 |
| 温度曲線 | 出だしは低くゆっくり → 中盤でツッコミと熱量 → 最後はスッと大人の余韻 |
| 引き算の美学 | 削いだ余白＝余韻。重く長い自分語りは「おじさんの独白」 |

**禁止**: 「フリオチ」「逆マウント」等のテクニック用語を文中に直出しすること（概念のみ使う）。

## 5. ギャップによる権威性（応用）

権威は「宣言」ではなく「落差」で生まれる。
普段は良客・楽しい人なのに、知識が必要な瞬間だけ「格が違う」精度がスッと出る——
「この人、何者？」という違和感が、肩書きの誇示より深い信頼を作る。
ドヤ顔・知識マウント・カタカナビジネス用語は逆効果（壁になる）。
