# Skill: content-engine — 媒体別コンテンツ設計

## 自動参照タイミング
- セールスレター・LP・ニュースレターの作成依頼（収益化フェーズの中核タスク）
- 既存資産（投稿実績・ナレッジ・SOP）を別媒体のコンテンツへ転用する時
- X以外の媒体向けコンテンツ（note記事・メルマガ等）を設計する時

> X投稿そのものの生成は既存パイプライン（`mini_bulk_generator.py` + `prompts.py`）が担当。
> 本スキルはその外側 — 収益化コンテンツと媒体展開 — を扱う。

---

## Core Rules（マルチAIの掟に準拠）

1. **長文のゼロから生成はGeminiオフロード**: セールスレター・LP・3,000字超の記事は、Gemini呼び出しスクリプト（`post_generator.py` のパターンを流用）を書いて生成させる。Claudeが直接長文を書かない（トークン浪費）
2. **Claudeの役割は構成設計と最終推敲**: アウトライン・訴求軸・プロンプトを設計し、Geminiの出力をブランドガイドラインに合わせてリライトする
3. **媒体ネイティブに書く**: 同じ文章を複数媒体にコピペしない。媒体ごとに構成から変える
4. **1コンテンツ1メッセージ**: 詰め込まず、明確な1つの主張に絞る
5. **具体が標語に勝つ**: 「節税できます」ではなく「社宅規程で年XX万円の差が出る」

## ペルソナ整合（必須）

すべての成果物は `apps/auto-poster/.claude/rules/persona.md` に従う:
- 一人称「ぼく」・二人称「あなた」、完全標準語、暴言禁止
- Markdown太字（`**`）禁止 → 【】や■で強調
- ナレッジ外の数字・法令の捏造禁止（国家資格者の信用に直結）
- 株式会社MiChi・個人情報・本文内URL（X投稿のみ）禁止

## 媒体別ガイド

### X（投稿・スレッド）
- 冒頭で掴む: 誤解フック型（「〜は関係ない」←この認識は間違い）が実測最高IMP
- 1ポスト1アイデア、ハッシュタグ乱用禁止
- CTAは2段階導線（固定ツイート → DM）のみ

### セールスレター / LP（社宅規程パッケージ等）
- 構成: 痛みの特定 → 放置コストの数値化 → 解決策の提示 → 権威（Big4出身CPA） → オファー → リスク反転 → CTA
- 法令・判例の引用は正確に（QC審査3基準をLPにも適用する）
- 煽り表現禁止: 「知らないと損」はOK、「業界の闇を暴露」系の誇大表現はNG
- 価格・返金条件などのオファー条件は必ずユーザーに確認してから記載する

### ニュースレター / note記事
- 1通1レンズ（無関係なトピックを束ねない）
- 見出しだけで内容が追える構成にする
- 冒頭1段落で「読む理由」を提示する

## リパーパスフロー（1ソース → 多媒体展開）

1. **アンカー資産を特定**: 高AlgoScore投稿・SOP・ナレッジExcel・月次レポート
2. **アトミックアイデアを3〜7個抽出**: 各アイデアは単独で成立する主張に分解
3. **媒体ネイティブ変換**: 各アイデアを媒体別ガイドに沿って変換（長文はGeminiへ）
4. **重複削除**: 媒体間で同一文面が残っていないか確認
5. **CTA整合**: 媒体の文脈に合うCTAへ調整（XはDM導線、LPは購入導線）

実績データの参照: 月次Analyticsの高AlgoScoreカテゴリ・フォーマットを「何が刺さるか」の根拠として使う。

## ペルソナv2「3つの顔」長文コンテンツ生成（定額LLM用マスタープロンプト構成）

X記事・note記事・ニュースレターを NotebookLM / Gemini ULTRA で生成する際は、
以下の構成でマスタープロンプトを組み立てること（短文ポスト用は
`apps/auto-poster/ingest_raw_contents.py --print-prompt` が自動生成するため二重管理しない）:

1. **アイデンティティ**: 「メンエスを愛する一人の良客。たまたまBig4出身CPA」＋3つの顔
   （良客=主役 / 頼れる専門家=ギャップ / 話すと楽しい人=奥行き）
2. **人蕩し術エッセンス**: 愛（相手の幸福を願う前提で書く）・陽気さ（ユーモアの底流。
   暗い話も最後はそっと上向きに）・自己重要感（承認は具体的事実から）・
   群居衝動（孤独への寄り添い・感情の先回り言語化）
3. **おもろい話し方**: フリオチ構造・巧みな例え・感情のリアル言語化（擬音・情景）。
   長文では「静かな出だし → 中盤でテンポを上げる → 大人の余韻で引く」の温度曲線を指定する
4. **絶対ルール**: `apps/auto-poster/.claude/rules/persona.md` の絶対ルール＋守秘フィクション化＋
   媚び禁止をそのまま転記する
5. **出力フォーマット**: 媒体別ガイド（上記）＋検証可能な構造指定

### 将来の収益化フロー（金曜ロードショー理論 — docs/knowledge/X_Operations/features/ 参照）

## Quality Gate（納品前チェック）

- [ ] 媒体ネイティブに読めるか（コピペ転載になっていないか）
- [ ] フックが具体的か（一般論・スローガンで始まっていないか）
- [ ] persona.md の絶対ルールに全文が準拠しているか
- [ ] 法令・数字がナレッジベースの範囲内か（捏造ゼロ）
- [ ] CTAが媒体と読者の温度感に合っているか
- [ ] QC審査3基準（法令精度・暴言・事実確認）を通過するか
