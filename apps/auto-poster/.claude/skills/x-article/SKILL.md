# Skill: x-article — X記事（長文記事機能）生成・推敲

## 目的

@Keita_CPA のX記事（Premium限定の長文記事機能）として「お金と法律のお守り」長文版を作る。
セラピストが搾取・誤解・税務の不安から身を守るための知識資産を、2,000〜4,000字の記事として公開し、
「いざという時に頼れる専門家」の信頼を積み上げる。将来のnote導線
（note蓄積 → Xつまみ食い → 代表作をX記事で全文公開。実証: X記事196万imp・note流入4,400）の土台。

**生成ルートは定額Gemini ULTRA**（生成コスト0円）。Claudeは構成設計・ハンドオフプロンプト組み立て・
推敲レビューに専念し、本文をゼロから書かない（content-engine原則）。
実行フローは `/project:introduce-therapist` 等と同じく `.claude/commands/write-article.md` が司る。

## 記事の型（X記事ガイドのベストプラクティス × ペルソナv2）

### タイトル（最重要・公開前にユーザーと3案から選定）

- 具体的で、好奇心を刺激し、価値を約束する。「2026年の節税のヒント」のような総称タイトルは禁止
- 実証済みフックの転用: **誤解フック型**（「チップだから申告しなくていい」←この認識は間違い。実測最高IMP）
- 「知らないと怖い」の恐怖煽りではなく「知っておくと安心（お守り）」の方向で

### 構成（スキミング構造 — 読者はまず流し読みする）

1. **冒頭フック**: 最初の1〜2文で「自分のことだ」と手を止めさせる。静かな出だし（テンションの高い煽り禁止）
2. **本文**: 1段落は2〜4行・1段落1アイデア。3〜5段落ごとに小見出し。重要な洞察は太字で強調
3. **具体例で示す**: 法令・数字の主張には必ず根拠（ナレッジ内の条文・判例・数字）と
   「中学生でも直感的にわかる」平易な翻訳を添える。守秘フィクション化した「よくある一場面」で体感させる
4. **締め**: 要点のまとめ → そっと上向きの一文 → 体験質問（リプライ誘発）＋著者全員返信宣言。
   pushyなCTA・外部誘導は禁止（CTA設計の低圧力原則）

### 文字数・温度曲線

- 2,000〜4,000字（執筆後に20〜30%削る前提で初稿はやや厚めに）
- 温度曲線: 静かな出だし → 中盤でテンポを上げる → 大人の余韻で引く（content-engine共通）

## フォーマットルール（通常ポストとの違いに注意）

| 項目 | 通常ポスト | X記事 |
|---|---|---|
| Markdown太字・見出し | 禁止（生テキスト表示されるため） | **使用する**（記事エディタは書式対応。原稿はMarkdownで書き、入稿時に手動で書式設定） |
| 箇条書き | 禁止（純文学フォーマット） | 使用可（冗長な文章よりリストが読みやすい） |
| 絵文字 | 禁止 | 禁止（cp932対策・世界観維持。変更なし） |
| 本文内URL | 禁止 | 原則禁止（note導線フェーズで解禁を再検討） |
| ヘッダー画像 | OGP自動生成 | 入稿時に手動選定（記事を開かせる重要要素） |

## 絶対ルール（全継承・例外なし）

- ペルソナv2絶対ルール: 一人称「ぼく」・二人称「あなた」・「彼女」「この子」禁止（「セラピストさん」）・
  関西弁禁止・説教/媚び禁止・性的ニュアンス禁止
- v3 NGトーン・温度感: ポエム語（魔法・奇跡・賜物・一体感）禁止 / 嘘くさい称賛（完璧・極上・感動しました）禁止 /
  「プロ」呼称禁止（自身は「専門家」）/ 評論家エッセイ調禁止 / 「。笑」表記禁止・括弧ツッコミ禁止
- ナレッジ外の数字・法令・条文番号の捏造禁止（RAG制約・国家資格者の信用に直結）
- X上では個別具体的な税務判断（「あなたの場合はこう申告すべき」）を行わない
- 守秘フィクション化: 施術中・相談エピソードは特定不可能な再構成のみ
- 自社名（株式会社MiChi）・自社URL・個人情報の記載禁止

## 多層レビュー（4層 — 書くAIとチェックするAIを分離する）

| 層 | 担当 | 内容 |
|---|---|---|
| ① 生成 | Gemini ULTRA（定額） | ハンドオフプロンプトから初稿を生成 |
| ② 機械チェック | Claude | 文字数（2,000〜4,000字）・NGワード・絵文字混入・見出し間隔（3〜5段落ごと）・1段落の行数 |
| ③ 品質審査 | Claude | QC3基準（法令精度・暴言/説教・事実確認）＋ v3トーン（評論家調・媚び・守秘・読後感）＋ 20〜30%の削り推敲 |
| ④ 最終確認 | 人間 | 通読 → X記事エディタへ入稿（太字・見出し・画像の書式設定） |
