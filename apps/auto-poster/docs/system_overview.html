ゴール（North Star）はフォロワー数ではありません。
セラピストと個人的な信頼関係を築き、お金・税・法律・将来の相談DMが自然に届くこと。 フォロワー・バズ・インプレッションはすべて副次指標です。 だから「アカウントが伸びない」の正しい問いは「セラピストとの会話が増えているか」です。

1. 全体マップ — 機械がやること／あなたがやること

土台: メイン投稿の永久機関全自動 knowledge.xlsx → Gemini生成 → ストックCSV → ConoHaが毎日1〜2件投稿。 役割は「プロフィールに来た人への信頼の裏付け（陳列棚）」。これ単体では伸びない。
＋ ここに交流エンジンを重ねる（2026-07-02 稼働開始）
返信し返し起案自動 自分の投稿への返信を毎朝取得し、返信案を用意。アルゴ加点+75で全アクション中の最重量。
リプライ（sniper）起案自動 セラピスト25名+の投稿を監視し、共感リプライ案を毎朝最大6件起案。
引用リポスト（quote）起案自動 実測最高フォーマット（AlgoScore=44）。代弁・承認コメント案を毎朝最大4件起案。
新規発掘（scout）週1自動 税・お金の不安を投稿する新しいセラピストを毎週月曜に発掘（業者除外済み）。
↓ 毎朝7:30、結果が1枚のメニューになってブラウザが勝手に開く
あなたの仕事はこれだけ1日5〜10分 開いたメニューを上から読む → 良い案は「返信画面を開く」を1クリック → 投稿ボタンを押す。 違和感のある案は直すか捨てる。記録・管理作業はゼロ（履歴はCSVが自動管理）。
↓ 会話が積み重なると
ゴールへの因果の鎖 会話 → 「見てくれてる人」として認知 → プロフィール訪問 → 過去投稿（陳列棚）で信頼確認 → フォロー → 困りごとが起きた日に「あの人に聞いてみよう」→ 相談DM

2. 「やっても効果がないのでは」への回答 — 全部実測値です

実測された事実意味
987投稿してフォロワー150 ブロードキャスト（一方的な投稿）は届かない、という反証がすでに手元にある。だからメイン投稿を増やす方向はやらない。
リプライはメイン投稿の8.1倍のIMP効率。全AlgoScoreの89%がリプライ由来 このアカウントの成果は、ほぼすべて「会話」から生まれている。交流エンジンに寄せるのはデータの帰結。
交流に力を入れた週（6/18〜24）だけ、返信+230%・いいね+325%・エンゲージ率+96% 「交流すると数字が動く」は既に自分のアカウントで再現済み。問題は継続できなかったことだけ。
6/21の投稿1件でフォロワー+82（全期間最大） 資産（メイン投稿）は交流で人が来たときに初めて効く。順序は交流が先。
2026年アルゴリズム: 著者の返信し返し+75／ブックマーク+10／いいね+0.5 「もらった返信に返す」は、いいね150個ぶんの重み。1日3件返すだけで最大級の打ち手になる。

出典: 月次Analytics実測（2026-04, 2026-06）・X公開アルゴリズム（Grokモデル・2026）。

効果が出る順番に注意。フォロワー数は最後に動く遅行指標です。 先に動くのは「返信が返ってくる率」→「プロフィールクリック」→「フォロー」→「DM」。 最初の2〜3週間はフォロワーがほぼ動かなくて正常です。そこで折れないために、下の「見る数字」だけを見てください。

3. あなたの行動 — 全部で3つだけ

  1. 毎朝（5〜10分）: 7:30に勝手に開くメニューを上から処理する。気が乗らない日は「1. 返信し返し」だけでもよい（最重量なので）。
  2. 毎週月曜（+3分）: メニュー末尾の「新規ターゲット候補」を見て、個人セラピストなら target_accounts.txt に1行追記する。
  3. 毎月1回: X AnalyticsのCSVを落として /project:monthly-analytics。数字が動いているかを確認し、動いていなければ戦略を直す。

メニューが開かなかった日: apps/auto-poster/run_daily_menu.cmd をダブルクリックすれば手動で作れます。

4. 見る数字（これ以外は見ない）

指標いまの基準値4週間後の合格ライン
週の交流数（返信し返し＋リプライ＋引用）ほぼ0（エンジン休眠中だった）週20件以上を4週続ける
セラピストからの返信・いいね返し散発「名前を覚えてもらえた」相手が3人
プロフィールクリック→フォロー転換未計測月次分析で計測開始
DM・パーソナルな会話の発生0焦らない。8〜12週スパンの成果
撤退基準も決めておきます（ダラダラやらないため）。 週20件の交流を8週間続けても、セラピストとの双方向の会話（相手からの返信）が月5件未満なら、 このアプローチは失敗と判定して戦略を作り直す。逆に言えば、それまでは数字が小さくても続ける価値がある—— やめる基準が明確なら、迷いながら続ける必要がないからです。
