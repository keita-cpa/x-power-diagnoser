# 実装計画: アカウント資産化リストラクチャリング（交流エンジンへの転換）

## 目的
フォロワーゼロ期に「メイン自動投稿の永久機関」が無風で空回りしている状態を脱し、
アカウントを「自動発信機」から「共感・交流支援機」へ再構成する。
最終目的は**収益化ではなく**「純粋に頼られる信頼関係の構築」と「フォロワー増による影響力（SNSの楽しさ）」。
**マイナス評価（Show Less / 興味なし / スパム判定）を絶対に避ける**ことを全設計の上位制約とする。

## 戦略の核（なぜこの順序か）
実測データ: リプライは1件あたり平均IMP 1,079 / メイン投稿は134（**8.1倍**）。
フォロワーゼロではメイン投稿は誰のTLにも乗らない。よって:
- **獲得エンジン = リプライ**（VIPの観客を借りる・プロフィールクリック誘発＝×4シグナル）
- **増幅エンジン = 引用リポスト**（実測最高フォーマット AlgoScore 44・専用ツールが現状ゼロ＝最大の機会損失）
- **資産（受け皿）= メイン投稿**（量ではなく、プロフ訪問者をフォローに変える「質の陳列棚」へ）

## ユーザー確定事項
- 北極星指標: フォロワー数＋純粋な相談DMの発生（信頼）。収益化は目的にしない
- 最優先着手: **リプライ戦略の再設計**
- 自動化方針: **起案は自動・投稿は手動承認**（マイナス評価リスク最小）
- メイン投稿: 1日4件 → **1〜2件へ削減・分散**

## 炎上回避ルール（全実装の必須条件・例外なし）
1. **指摘・説教・求められないアドバイス完全禁止**。リプライ/引用は「全肯定・共感・事実の承認」のみ
2. 専門知識（法・税）は**相手が明確に質問・相談している時だけ**、しかも「お守り」の温度で。未要求の場面では一切出さない
3. 引用リポストは「相手が自分のフォロワーに見せたい＝リポストで返したくなる」内容に。相手の**見えない努力・気遣いを代弁**する
4. **同一アカウントへの連続接触を防ぐインターバル制御**（スパム判定回避）
5. **AI定型文の排除＋温度ランダム化**（「〜ですよね」「〜の賜物」等の頻発・テンプレ臭を構造的に防ぐ）

## KPI / マイルストーン（北極星: フォロワー数＋純粋な相談DMの発生）
### ファネルKPI（毎週確認）
丁寧なリプライ＋引用 5〜10件/日 → 借り受けたIMP → プロフィールクリック → フォロー転換 → 相談DM
- 先行指標: 1日の起案→承認投稿数（5〜10件）／同一人物への72h以内の重複接触ゼロ
- 健全性指標: **Show Less・興味なし・ミュート・ブロックの発生ゼロ**（最上位・マイナス評価の絶対回避）
- 遅行指標: 週次フォロワー純増／プロフィールクリック数／自然発生DM数

### マイルストーン
- Phase 1（0〜300フォロワー）: 交流に全振り。リプライ＋引用を1日5〜10件。専門知識は求められた時のみ。メイン投稿1〜2件/日
- Phase 2（300〜）: TLにIMPが乗り始める。「お金と法律のお守り」投稿が資産として効き始める。相談DMが自然発生
- Phase 3（将来）: 北極星をDM相談（信頼の質）側へ寄せ、monthly-analyticsで転換率を計測（D3）
