# 実装計画: zoning_checker.py — エリア適法性チェックCLIツール

## 目的

住所入力→用途地域判定→メンエス営業可否を数秒で出力するKeita_CPA専用CLIツール。
セラピストが「このエリアで開業しようか」とXでつぶやいたとき、即座に正確な情報でリプライできる。
リプライ（×5シグナル）+ 頼れる専門家ギャップ → North Star（DM相談）への最短導線。

## ミニマム版スコープ

- 住所入力 → 緯度経度（国土地理院ジオコーディングAPI・無料・登録不要）
- 緯度経度 → 用途地域（国土数値情報GMLファイルをShapelyで判定・ローカル処理）
- 用途地域 → 営業可否（建築基準法ルールの静的マッピング）
- Xリプライ用の短文テキストを自動生成

## 影響範囲

新規アプリ: `apps/zoning-checker/`
```
apps/zoning-checker/
```

| データ | 提供元 | 方式 | コスト |
|---|---|---|---|

| 用途地域ポリゴン | 国土数値情報「用途地域（A29）」GML | ローカルファイル | 無料・要DL |

## 懸念事項・リスク

- `shapely` のWindowsインストールは最近改善済み（wheel提供）、`pip install shapely` で入るはず
- 国土数値情報GMLは都道府県別で各数十MB。全国分は初回DL・前処理に時間がかかる
- 同一住所でも番地の精度次第でポリゴン境界付近で誤判定の可能性あり（免責表示で対応）
