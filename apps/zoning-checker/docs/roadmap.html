自動化マップ — 何がどのツールで自動化できるか

タスク 自動化レベル ツール 工数 メモ
GML 1都道府県DL（利用規約同意込み） 半自動 claude-in-chrome 5分 利用規約クリック→DLリンク特定→DL実行まで自動化可
GML 全都道府県一括DL 半自動 claude-in-chrome 30〜60分 47ページをループ処理。サーバー負荷に注意（インターバル必要）
GML → pickle 前処理 完全自動 Python（実装済み） 2分/都道府県 setup_data.py を実行するだけ
住所 → 用途地域判定 完全自動 Python（実装済み） 即座（1秒以内） zoning_checker.py --address で即時判定
Xリプライテキスト生成 完全自動 Python（実装済み） 即座 コピペするだけ。280字チェック済み
都道府県条例ページのスクレイプ+ルール化 半自動 claude-in-chrome + Claude Code 1〜2日 条例テキスト収集はclaude-in-chrome、ルール変換はClaude Codeで
contacts.csv 関係追跡システム 完全自動 Claude Code 4〜6時間 実装をClaude Codeに委ねられる。スキーマ設計が主な判断事項
X DM受信→住所抽出→判定→返信案 完全自動 Claude Code 1日（X API加入後） X API Basic（$100/月）が前提。送信は手動承認を推奨
claude-in-chrome の主な役割: 国土数値情報サイトの利用規約クリック→ファイル一覧ページのDLリンク特定→ダウンロード実行。 47都道府県分をループで処理させれば、手動作業の大半をなくせる。 ただし サーバー負荷に配慮し2〜3秒のインターバルを設けること。
