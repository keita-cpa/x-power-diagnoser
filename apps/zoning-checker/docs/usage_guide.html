1. 基本の使い方

住所 → 1コマンド → リプライ文

全国47都道府県・104,702ポリゴン対応。ターミナルで1行叩くだけ。

1
ターミナルでコマンドを実行
# apps/zoning-checker/ ディレクトリで実行
python zoning_checker.py --address "京都府京都市南区"
2
出力を確認

------------------------------------------------------------
座標:     緯度 34.976650, 経度 135.746429
用途地域: 近隣商業地域
判定:     [OK]  問題なし
備考:     制限なし

[X リプライ用テキスト]
このエリアは 近隣商業地域 です。エステ・サロン系の
営業は建築基準法上 問題なし の区域になります。
ただしテナントの建物用途や消防法・条例の確認は

2. Gem連携でリプライ案を自動生成

Gemini ULTRAとのハイブリッド運用

Gemに住所を直接入れて全部やってもらう方法は実現できません。
Gemからは国土地理院APIもローカルPickleファイルも呼べないため、ジオコーディング（住所→座標）とポリゴン判定（座標→用途地域）はPythonスクリプト側が行う必要があります。

推奨: 2段階ハイブリッド運用

セラピストDM「○○で開業考えてます」
→
zoning_checker.pyターミナルで1コマンド
→
結果をコピー用途地域名＋判定
→
Gem（DM返信Gem）@Keita_CPA口調に整形
→
DM返信コピペして送信

Gemに渡す入力テンプレート

【住所】京都府京都市南区
【用途地域】近隣商業地域
【判定】OK（問題なし）
【備考】制限なし
【セラピストの文脈】「南区で物件を探していて、サロンを開きたい」と相談
zoning_checker.py の出力からそのままコピペしてもOKです。
【セラピストの文脈】には相手が送ってきたDMの内容を貼るとGemがより自然な返信を生成します。

Gemが返してくれる出力例

南区、確認してみました。 近隣商業地域なので、建築基準法の観点では問題なしのエリアです。サロン系の営業は普通にできます。 ただテナントの建物用途（「事務所」名義など）や消防法の確認は入居前にやっておくと安心ですよ。何かあればまた聞いてください。

6. 現在の制約と対処法
制約詳細対処法
未対応
那覇市		 国土数値情報（令和元年版）に那覇市のポリゴンデータが未収録 「那覇市役所の都市計画課で確認できますよ」と案内
注意
番地精度		 「○○区」だけの入力は区の中心座標になる。ポリゴン境界付近で誤判定の可能性あり 「丁目番地まで」の住所で再確認を促す
注意
全自動化不可		 GemにAPIアクセス機能がないため、住所入力だけで完結しない 2段階ハイブリッド運用（Python→Gem）で対応
免責
参考情報		 建築基準法の用途地域のみの判定。条例・消防法・建物用途は別途確認が必要 毎回の返信に免責一言を添える（Gemプロンプトに組み込み済み）
